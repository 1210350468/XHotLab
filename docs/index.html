FAQ

常见问题

XHotLab 是什么？

它是 Windows 本地运行的开源 X / Twitter 内容发现与发布准备工具，包含中文热门浏览、视频素材管理、发布队列和 Edge 扩展。

怎么把抖音视频发到 X？

CreatorHub 负责采集与下载，XHotLab 检查媒体文件、管理文案，并通过 Edge 扩展打开 X 编辑器。最终发布由用户在浏览器中完成。

会自动附加作者或生成文案吗？

首页采用手动编写正文，按实际输入内容准备发帖。原作者与视频链接保存在素材信息中，供用户核对。

Does XHotLab automatically publish posts on X?

XHotLab prepares selected media and user-written text in the official X composer. The signed-in account owner reviews and submits the post.
